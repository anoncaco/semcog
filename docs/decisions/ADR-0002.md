# ADR-0002: 임베더 백엔드 간 모델 동일성 판정과 인덱스 격리

- **상태:** 확정 (Accepted)
- **일자:** 2026-10-20
- **관련:** `summary_arch.md` §2 C12, §6.2, §6.3, §19 #1·#1b·#2, §16 Phase 0
- **기반:** 아키텍처 검토 M2

## 배경

§6.3의 임베딩 프로파일 레지스트리는 `backend` 필드로 ST와 Ollama를 구분한다. 하지만 **두 백엔드가 같은 모델을 담고 있는지 확인하는 절차가 문서에 없었다.**

실제로 두 경로의 대상 모델은 표기가 다르다.

- ST 경로: `google/embeddinggemma-2` (`doc/embedder_reference.md` §1 — 740M, 텍스트 전용 로드 시 270M)
- Ollama 경로: 로컬 태그 `embeddinggemma` (`doc/continue_input.md` §3 — 버전 미상)

§6.2 규칙 2는 "프로파일·모델 태그·차원·정규화·task prefix가 바뀌면 새 프로파일 + 새 인덱스 버전을 만들고 재색인한다. 기존 벡터와 새 벡터를 병합하지 않는다"라고 규정하지만, **판정 절차가 없으므로 규칙이 적용될지 알 수 없다.** 서로 다른 모델의 벡터가 같은 인덱스에 들어가고 서로 비교되면, 검색 결과가 무의미해진다.

§6.2 규칙 5는 "임베딩 프로파일 불일치는 경고가 아니라 오류다"고 규정한다. **이것을 판정하려면 동일성 판정이 먼저 있어야 한다.**

## 검토한 대안

| 대안 | 평가 |
|---|---|
| (a) ST만 사용하고 Ollama는 빼버린다 | C5가 요구한 백엔드 선택 절차를 무시한다. Phase 0의 목적(실사용 가능한 쪽 확정)을 훼손한다. **기각** |
| (b) 두 백엔드 결과를 무조건 비교 | 서로 다른 모델이면 비교 자체가 무의미하다. **기각** |
| **(c) Phase 0에서 동일성을 판정하고, 다르면 완전 격리** | **채택** |

## 결정

**Phase 0에서 백엔드 간 모델 동일성을 판정한다.**

판정 항목:

1. **모델 식별자** — ST: `google/embeddinggemma-2`. Ollama: 로컬 태그가 실제로 가리키는 모델. Ollama가 digest/모델 정보를 제공하는지 확인한다.
2. **digest 대조** — 양쪽이 동일 모델을 가리키면 digest가 일치해야 한다. **digest를 확인할 수 없는 백엔드는 임의 문자열로 대체하지 않는다.** 확인 불가로 기록한다.
3. **출력 차원·노름·유한성 대조** — 동일 모델이라면 차원·노름·정규화 방식이 같아야 한다.
4. **판정 결과를 `results.json`에 기록** — `same_model: true | false | undetermined`.

판정 결과에 따른 처리:

- `same_model: true` → 하나의 프로파일군으로 취급하되, **여전히 backend 필드로 구분**하고 벡터 직접 비교는 금지.
- `same_model: false` → **§6.2 규칙 2에 따라 완전 격리.** 별도 프로파일 + 별도 인덱스. **동일 인덱스 상에서 비교·병합·재순위를 절대 하지 않는다.**
- `same_model: undetermined` → `false`와 동일하게 취급한다(안전 쪽). 단, 이 경우 Phase 0 판정은 **보류**가 아니라 "Ollama 경로는 사용 가능하나 ST와 비교 불가"로 기록한다.

**멀티모달 수용 여부는 별도 판정**이다(C5). ST가 이미지를 받는 것과 Ollama가 받는 것은 별개의 기능 테스트다. **확인되지 않은 백엔드로 멀티모달을 시도하지 않는다.**

## 결과

- §6.2 규칙 2·5가 실제로 적용 가능한 상태가 된다.
- Phase 0의 통과 기준에 "모델 동일성 판정"이 명시되어, 백엔드 선택이 재현 가능해진다.
- `z_raw`/`z_mrl`/`z_abs` 규칙(§6.1)은 프로필 단위로만 적용되므로, 격리되어도 규칙 위반이 되지 않는다.
- **§19 #2(실측 차원·digest)는 "확인 불가"가 답일 수 있다.** 이 경우 임의 값으로 채우지 않고 확인 불가로 남긴다.

## 잔여 위험

- Ollama가 모델 메타데이터를 제공하지 않으면 `undetermined`이 될 수 있다. 이 경우 ST 경로를 v1 기본 경로로 삼고, Ollama는 별도 프로파일로만 사용한다.
