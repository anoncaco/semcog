## 1. 한 줄 요약

**인지 코어 `F`가 컨텍스트를 저장하고, 기억을 검색하고, 추론·검증·상태 갱신을 수행한다.** 그 바깥에 입출력 모듈과 기억 계층, 그리고 구조 자체를 실험으로 바꾸는 메타 계층을 둔다.

## 2. 모듈 지도

| 모듈 | 책임 | 권위 |
|---|---|---|
| **A** 입력 어댑터 | 임의 모달리티 → 임베더 입력 정규화 | ✗ |
| **E** 인코더 | 의미 벡터 생성 (고정, freeze) | ✗ |
| **Parse** | 명시적 관계·속성 후보 추출 | ✗ (검증 전) |
| **Registry** | 컨텍스트 ID·원본·해시·벡터 버전 관리 | 원본/출처 기준 저장소 |
| **F / STATE** | 현재 문제·가설·근거 관리 | **✓ 상태 전이의 기준** |
| **M** 기억 | 벡터 검색 + 기호 조회 | ✗ (저장은 담당) |
| **R** 추론 | 추론 후보 생성 | ✗ |
| **V** 검증 | 근거·반증·모순·종료 판정 | ✗ (판정 결과 기록) |
| **META** | 구조 진단·제안·샌드박스 | ✗ (승인 없이는 변경 못 함) |
| **P** 투영 | STATE → JSON | ✗ (뷰) |
| **D** 생성기 | 자연어 출력 | ✗ (**출력은 자동 사실 아님**) |
| **Eval** | 측정·회귀·ablation | 실험 결과 기록 기준 |

## 3. 3루프

| 루프 | 내용 | 권위 |
|---|---|---|
| 인지 루프 | 컨텍스트 생성 → 기억 검색 → 추론 → 검증 → 상태 갱신 (반복) | F |
| 학습 루프 | 경험 축적 → 규칙 후보 추출 → 적용 → 성패 기록 | R + Learning |
| 메타 루프 | 구조 한계 진단 → 변경안 제안 → 격리 평가 → 승인/롤백 | META |

## 4. 가장 중요한 규칙 5개

1. **E와 D는 입출력 모듈이다. 지속적 지식 상태의 권위 있는 소유자는 F뿐이다.**
2. **`content_hash`(식별) · `z_raw`(의미) · `z_mrl`(축소) · `z_abs`(학습) 는 네 개가 서로 다른 것이다.** 같은 필드·같은 인덱스에 섞지 않는다.
3. **벡터 유사성은 검색 신호이며 논리적 참/거짓 판정이 아니다.** 판단은 관계·출처·검증(V)이 한다.
4. **D가 만든 문장은 자동으로 사실이 되지 않는다.** `llm_generated` 출처의 **가설 후보**로만 저장한다.
5. **구조 변경과 파라미터 학습을 한 번에 동시에 하지 않는다.** 각각 별도 버전·별도 실험으로 평가한 뒤 조합한다.

---

## 5. 표현 체계 4분류

| 표현 | 정체 | 사용 금지 |
|---|---|---|
| `content_hash` | 정규화 콘텐츠의 결정적 해시 | 의미/유사도 계산, 검색 스코어 |
| `z_raw` | 고정 임베더의 원본 임베딩 | 자르지 말고, 논리 진위 판정 |
| `z_mrl` | `z_raw`의 MRL 절단본 (재정규화) | `z_abs`와 혼용, 동일 인덱스 혼합 |
| `z_abs` | 별도 학습 모듈의 추상 표현 | 승격 검증 전 기본 경로 사용 |

---

## 6. 상태 전이

가설 상태 전이 표(§7.5)는 **선언적**(`configs/structure_registry.yaml`)이고, 표에 없는 전이는 **거부**된다.

- **`supported → rejected` 직행 금지.** `weakened` 또는 `unresolved`를 거친다.
- **`rejected`에서 되돌아오는 전이는 사유 필수.**
- 모든 전이는 `apply_transition(state, transition, reason)`을 통과한다. `reason`이 비면 거부.
